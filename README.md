# QuiXam · 试卷编排工作台

面向中学教师的低门槛试卷编排平台。当前聚焦**高中**，格式对齐中国试卷惯例（高考卷版式）。

打开即是一张符合规范的试卷：题号全卷连续、大题序号"一、二、三"、分值自动汇总校验、选项按宽度自动排 4/2/1 列、字体按部位自动套用（黑体做结构、宋体做内容、西文自动落 Times New Roman）——教师只管内容，排版交给系统。

## 功能

- 三栏工作台：结构导航 / 试卷画布（所见即所得）/ 属性面板
- 题型：单选、多选、填空、解答（答题区留白）、**材料题**（共享材料 + 子题，覆盖阅读理解/古诗鉴赏；材料楷体、`#` 居中标题、`@` 仿宋作者行）
- `$...$` 行内 KaTeX 公式（题干、选项、答案均可用）；化学式支持 mhchem，如 `$\ce{2H2 + O2 -> 2H2O}$`
- 题目附图（存 IndexedDB，导出 JSON 时内联 base64）
- 撤销 / 重做（Ctrl+Z / Ctrl+Y，连续输入合并为一步）
- 粘贴导入：从 Word 复制整卷文本，自动拆出大题 / 题目 / 选项 / 分值
- **扫描识别（BYOK）**：上传多张试卷图片或 PDF，由用户自己的多模态 API 按严格 JSON Schema 直接生成 QuiXam 试卷；识别后可预览大题、题数和分值，再新建试卷或追加到当前试卷
- 多试卷管理，IndexedDB 自动保存（本地优先，无需注册）
- 内置模板：空白卷 / 2024 年高考综合改革适应性测试数学、语文、英语完整原卷 / 物理、历史、化学、生物学、思想政治、地理完整结构模拟卷 / 浙江技术选考（信息技术 + 通用技术）完整结构模拟卷
- JSON 导入导出（备份与教师间交换）
- **真分页预览**：画布上就是一页一页的纸，屏幕所见的每一页即打印出来的每一页；每页带密封线与"第 X 页 共 Y 页"页脚。内容绝不溢出页边——语文/英语文章材料可从任意文本行续到下一页，答题区按行切、留白按高度切、其余先换页；"整题不跨页""大题标题不落单"是可开关的偏好
- 一键打印 / 导出 PDF：A4 单栏或 **A3 横向两栏（8K 对折卷）**，可选**密封线**，教师版附参考答案另起一页
- 排版档位：正文字体（宋/楷/黑）、字号（五号/小四/四号）、行距

## 开发

```bash
pnpm install
pnpm dev      # 开发服务器
pnpm build    # 类型检查 + 构建
pnpm lint     # ESLint
pnpm test     # 单元测试（vitest）
```

技术栈：React 19 + TypeScript + Vite（React Compiler 已启用）、zustand、idb、KaTeX。

## 扫描识别与 BYOK

顶栏的扫描图标用于导入图片或 PDF。首版兼容同时支持 OpenAI Responses API、视觉输入和严格 JSON Schema 的接口，默认模型可编辑；PDF 会作为文件直接交给模型，不先生成一份 OCR 中间结构。

- API Key 保存在当前站点的浏览器 `localStorage` 中，重新打开弹窗会自动填充；清空输入会同时删除已保存的 Key。它不会写入 IndexedDB、试卷 JSON、URL 或日志。
- 图片/PDF 由浏览器直接发往用户填写的 API 地址；自定义地址会收到该 Key，因此只应使用可信且支持浏览器跨域访问（CORS）的服务。
- 应用仍会在本地校验模型输出，并只补齐 `id`、时间戳和固定排版默认值。
- 首版聚焦文字、公式、材料和题目结构。原卷图表会在对应位置保留 `[图表见原卷]` 标记，暂不自动裁切为题图；所有识别结果在付印前都应对照原卷复核。

## 内置套卷来源与标识

三科内置卷均为教育部教育考试院命制并公开的 **2024 年高考综合改革适应性测试**，不是自编模拟题：

- [语文原卷（中国教育考试网）](https://www.neea.edu.cn/html1/report/2401/376-1.htm)，模板采用河南、黑龙江、甘肃的“交错带”作文版本
- [数学原卷（中国教育考试网）](https://www.neea.edu.cn/xhtml1/report/2401/426-1.htm)
- [英语原卷（中国教育考试网）](https://www.neea.edu.cn/html1/report/2401/499-1.htm)

原卷没有随题面公开完整主观题解答，因此模板不补写自编范文或解答；答案页只保留核验过的客观题、名句默写和语法填空答案。

物理、历史、化学、生物学、思想政治、地理属于省级选择性考试科目，没有与语数外相同的全国统一官方原卷。QuiXam 因此提供六套**原创高考结构模拟卷**，按江苏公开结构的 75 分钟、100 分完整卷组织，用于覆盖理科实验图、化学式/工艺流程、区域图表和文科长材料分页。题型设计参考江苏省教育考试院公开的[选择性考试科目试卷结构](https://www.jseea.cn/webfile/index/index_zcwj/2022-11-24/7001427998851207168.html)。

“技术”不是全国通用的第七门选择性考试科目。本项目按浙江选考口径提供一套 90 分钟、100 分的技术模拟卷，信息技术与通用技术各 50 分；地区和科目构成会显示在模板名、卷头和副标题中。依据见浙江省教育考试院的[选考科目实施办法](https://www.zjzs.net/art/2018/5/16/art_45_5651.html)和[2026 年招生工作通知](https://www.zjzs.net/art/2026/5/20/art_30_12294.html)。

上述七套模拟卷都不是历年真题，并在模板名称、卷头和模板说明中同时标注“非真题”，不会冒充官方试卷。
